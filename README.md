# Say vs. Do

Verificador de afirmaciones en directo: transcribe lo que se dice, detecta afirmaciones con Nemotron (Nebius) y las contrasta con evidencia de Tavily.
Cada afirmacion recibe un veredicto (SUPPORTED / MISLEADING / FALSE / UNVERIFIABLE) con su fuente.
Proyecto para Nebius Build Week x NVIDIA (Berlin, 18.10.2026).

## Setup

Copy .env.example to .env and fill keys.
